# Dogs of the Internet App

### Project Scope: A simple website to practice using APIs. This site is straightforward. Click the link and get your dose of digital oxytocin in the form of dog photos!

### Tech Used: 
- HTML, CSS, Vanilla JavaScript

![screenshot of web page with a cute dog on a calm beachy background](/css/screenshotWebPage.png)

### How to Run Project:
- Hit the link to the webpage in the 'About' section of this repo to the right!
- Practice with API's yourself by forking and cloning this repo. I used the DogCEO Api.
- We all need a little happiness dose sometimes. Enjoy!
